# New computer or new Claude account: mitali-portfolio

> Generated by `/dev-pipeline:machine-setup` from `.dev-pipeline/restore.json` on 2026-10-31 02:19. Do not edit by hand; change the manifest and regenerate.
> `<DEV_ROOT>` is the folder that holds your projects on this computer (any folder you choose, for example `D:\Work`). Nothing here contains a password, key or token.

## Fastest path (you only have this project and the marketplace)
You do **not** need to clone the toolkit repository. The Claude plugin comes from the marketplace, and the project carries its own restore script.
1. Install Git and Claude Code (see "Tools" below), run `claude` once, and sign in with the account you want on this computer.
2. Clone this project (see "Get the project" below).
3. In the project folder run: `powershell -NoProfile -ExecutionPolicy Bypass -File .dev-pipeline\restore.ps1` (add `-Install` to let winget install missing tools, after you confirm). It checks tools, clones the other repositories, creates the local files, and prints what is left.
4. In a Claude session add the plugin: `/plugin marketplace add nimesh-patel-1994/multi-agent-setup` then `/plugin install dev-pipeline@multi-agent-setup` (desktop app: Settings > Plugins).
5. Open the project with `open-claude.ps1` (or add the folders in the desktop app) and run `/dev-pipeline:resume`.

### Databases
Data does not travel through git. Recreate each database, then seed test data:
- `mitali_portfolio` (PostgreSQL 17 (port 5442)): backend/scripts/setup_db.ps1, then 'python -m uv run alembic upgrade head' and 'python -m uv run python -m app.cli seed' in backend (README, Backend)
- `mitali_portfolio_test` (PostgreSQL 17 (port 5442)): created by backend/scripts/setup_db.ps1; migrated by the test suite


### Other steps
- PostgreSQL 17 must listen on port 5442 (the installer default is 5432; set the port during installation). psql is not on PATH by default (it is in the PostgreSQL 17 bin folder under Program Files).
- Run backend/scripts/setup_db.ps1 yourself (it asks for the PostgreSQL superuser password and a new app-role password).
- Create the admin account: in backend run 'python -m uv run python -m app.cli create-admin --email <your email>'.
- Playwright browsers for the E2E tests: in frontend run 'npx playwright install chromium'.
- Optional: enable the secret-scan git hook once with 'git config core.hooksPath .githooks'.

## Starting the apps
- `start-classic.cmd` is the original launcher for `frontend/`: Brave first (else Chrome, else default), opens `/` and `/admin`,
  runs migrations on every start, `-Preview` for the production-like build, `-DryRun` to check first.
- `start.cmd` is the toolkit run kit (from `run/run.json`): Chrome first and only `/`; it migrates once on the first run and creates
  `frontend/.env` from `frontend/.env.example` on that first run. `stop.cmd` closes what it started.
- Both use the dev database `mitali_portfolio` on port 5442.

## Open and continue
- Run `open-claude.ps1` from the project folder, or in the desktop app add the project folder and start a session.
- Type `/dev-pipeline:` and check that the commands appear. If they do not, the plugin is not installed for this Claude account yet (step 4 above).
- Run `/dev-pipeline:resume`: it reads `.dev-pipeline/HANDOFF.md` and continues where the last session stopped.

## Moving work between computers (usage limit or a trip)
1. On the old computer: `/dev-pipeline:handoff`, then from a terminal run `/dev-pipeline:push-plan` output (or `git status` and `git push` in each repository listed there).
2. On the new computer: `git pull` in each repository, then `/dev-pipeline:resume`.
